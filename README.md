# Сквозь Землю — карта антиподов

Интерактивная карта: что находится точно на противоположной стороне планеты от каждого крупного города.

Антипод точки — место на другом конце диаметра Земли: широта меняет знак, долгота сдвигается на 180°. Если бы можно было прокопать тоннель через центр Земли из Мадрида, вы бы вышли в Новой Зеландии, а из Пекина — в Аргентине.

## Что умеет

- **185 крупных городов** со всех континентов. Для каждого видно, что на другой стороне: страна или океан, точные координаты, расстояние до ближайшей суши и ближайший город из списка.
- **Любая точка.** Нажмите в любое место карты — получите её антипод.
- **Перевёрнутый мир.** Слой с материками, отражёнными через центр Земли. Где малиновые контуры ложатся на сушу — там суша против суши.
- **Две карты.** Левая показывает выбранное место, правая — его антипод. Двигаете одну, вторая следует.
- **Мой антипод.** Определяет ваше местоположение и показывает, что под вами на другой стороне.
- **Поиск и фильтры:** по городу или стране, только пары «суша ↔ суша» или только антиподы в океане.
- **Ссылки на пары.** Адрес страницы меняется при выборе (`#40.4168,-3.7038`), им можно поделиться.
- Светлая и тёмная темы, работает на телефоне.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `antipodes`.
2. Загрузите в него файлы `index.html`, `app.js`, `core.js` и `README.md` (кнопка **Add file → Upload files** или через git):
   ```bash
   git init
   git add index.html app.js core.js README.md
   git commit -m "Карта антиподов"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/antipodes.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**, в разделе *Build and deployment* выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт будет доступен по адресу `https://<ваш-логин>.github.io/antipodes/`.

Сборка не нужна: это обычная статическая страница.

## Запуск локально

Страница загружает `core.js` и `app.js`, поэтому её нужно открыть через локальный сервер, а не двойным щелчком:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и стили |
| `core.js` | Список городов и вся геометрия: поиск страны по точке, антипод, ближайшая суша, названия океанов. Не зависит от браузера — можно подключить в Node |
| `app.js` | Карта на Leaflet, панель, синхронизация двух карт |

Как добавить город: допишите строку в массив `CITIES` в `core.js` — `['Название', 'Страна', широта, долгота, население в млн]`.

Точность. Поиск страны работает по контурам 1:50 млн, поэтому точки у самого берега иногда попадают в море. Расстояние до суши считается до ближайшей вершины береговой линии — погрешность несколько километров. Названия морей и океанов определяются по упрощённым границам и годятся для подписи, а не для навигации.
